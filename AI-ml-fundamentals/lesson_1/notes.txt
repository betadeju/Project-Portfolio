What “agent memory” means

Right now your assistant has only short-term memory, the recent messages that React sends each time. A fuller memory system has three layers:

-> Short-term memory: the last ~20 messages, sent word for word.
-> Summary memory: when the chat gets long, older messages are compressed into a short summary, so the AI keeps the gist without sending everything.
-> Long-term memory: lasting facts about the user (“Name is Sam”, “Is learning Python”), which are added to every future conversation
